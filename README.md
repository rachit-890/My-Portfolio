## 🎨 Portfolio Features & Tech Stack

This portfolio is built to offer a premium, cinematic experience for recruiters and collaborators.

### Key Frontend Features
*   **3D Interactive Elements:** Seamlessly integrated 3D models using **Three.js** and **React Three Fiber**.
*   **Smooth Motion & Animations:** Fully custom fluid scroll effects and timeline animations powered by **GSAP** (GreenSock Animation Platform) and **ScrollTrigger**.
*   **Modern Design & Layout:** Clean glassmorphism components, dark-mode aesthetics, custom cursor tracking, and responsive design.

### Tech Stack Used
*   **Core:** React (Vite), TypeScript, HTML5, Vanilla CSS
*   **Animation & 3D:** GSAP, Three.js, React Three Fiber, WebGL
*   **Deployment:** Render

## 🚀 Getting Started Locally

To run this portfolio website locally, follow these steps:

### Prerequisites
*   Node.js (v18+ recommended)
*   npm

### Installation & Run

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/rachit-890/My-Portfolio.git
    cd My-Portfolio
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the local development server:**
    ```bash
    npm run dev
    ```
    Open your browser and navigate to `http://localhost:5173` (or the port specified in your terminal).

4.  **Build for production:**
    ```bash
    npm run build
    ```
